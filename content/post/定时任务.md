### crontab
#### 查看所有定时
```
crontab -l
```

#### 编辑定时
```
crontab -e
export EDITOR=nano; crontab -e
```

#### 格式
每行一个定时，前为时间后为命令
```
* * * * * command

分 时 日 月 周几

分：0-59
时：0-23
日：1-31
月：1-12
周：0-6（日为0）

*： 每一
,： 或
-： 之间
/： 后跟数字表每几一次
```
