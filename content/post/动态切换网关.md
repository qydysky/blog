# 动态切换网关
住的附近正施工，光纤网络之前断了两次，于是购入了一个4g插卡路由，现在只需要让nas可以动态切换网关。

## linux
使用定时程序`crontab`注册如下脚本，实现网关切换。

```sh
#!/bin/sh
gw1="192.168.31.1";
gw2="192.168.31.66";

while:
do
    route del default;
    route add default gw $gw1;
    while ping -c 1 $gw1 &> /dev/null
        do
            sleep 1;
        done
    route del default;
    route add default gw $gw2;
    until ping -c 1 $gw1 &> /dev/null
        do
            sleep 1;
        done
done
```

定时任务的编辑与查看：

```
crontab -e
crontab -l
```
